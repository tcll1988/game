# 汉语小游戏（13 款）

爱知淑徳大学 中文课用的练习小游戏。界面以日语为主，全部是静态网页，**不需要安装、不需要编译**，直接放到 GitHub Pages 就能用。

## 目录结构

```
index.html          目录页（日语为主，附中文名），点击进入各游戏
games/
  01-tone.html         声調キャッチ（听声调）
  02-roleplay.html     お買い物クエスト（买东西：顾客 / 店员两种角色）
  03-detective.html    読解探偵（阅读侦探：初级 / 中级 / 高级只听录音）
  04-hanzi.html        漢字工房（汉字部件组字）
  05-whack.html        ピンイン・モグラ（听音打地鼠）
  06-weekly.html       今週のチャレンジ（每周挑战，可交成绩码）
  07-daily.html        每日一词（1 天 / 3 天 / 7 天后复习）
  08-voice.html        声調ミラー（声调镜子，需要麦克风）
  09-measure.html      量詞マッチ（量词配对）
  10-falsefriends.html その漢字、同じ意味？（中日同形词）
  11-shadowing.html    リピート＆シャドーイング（跟读，需要麦克风）
  12-wrongchar.html    その字、中国の字？（简体字辨别）
  13-order.html        時間順ならべ（按时间排序）
```

每个游戏页面左上角都有「← 目次」，可以回到目录页。

## 使用方法

- 打开 `index.html`，点击想玩的游戏即可。手机（iPhone / Android）和电脑都可以。
- 每个游戏都是一个独立的 HTML 文件，所有样式和程序都写在文件里面，只用相对路径。
- 录音来自老师自己的 GitHub Pages：
  - 单词录音：`https://tcll1988.github.io/HSK/audio/…`
  - 课文录音（第 10 课会话、第 11 课阅读）：`https://tcll1988.github.io/kaiwa-dokai/…`
  
  这两个网站需要保持公开，否则游戏里没有声音（游戏不会卡住，会显示「音声を再生できませんでした」）。
- 学生的成绩、连续天数等只保存在学生自己的浏览器里（localStorage，键名以 `cngame.` 开头），不会上传到任何地方。
- 08、11 需要麦克风：第一次使用时浏览器会询问，请学生选择「允许」。在 LINE、Teams 等 App 里直接打开时，麦克风和自动播放可能受限，建议用 Safari / Chrome 打开。

## 发布到 GitHub Pages（参考）

把本文件夹里的全部内容放到仓库根目录（`index.html` 在最上层），在仓库的 Settings → Pages 里选择 `main` 分支、根目录即可。网址会是 `https://<用户名>.github.io/<仓库名>/`。

## 关于内容

- 课文、单词、例句全部来自老师提供的材料（40 个单词、第 10 课会话、第 11 课阅读）以及各 AI 版本里已有的内容，没有另外编写新词条。
- 页面上标有「⚠先生確認」的地方，是说明文字或题目设计需要老师再确认的部分。
- 每个文件开头的注释（設計メモ）写有学习目标、玩法、合成时搬了哪些功能。
